# 附录 · 高风险场景专项验证(条件触发;片涉及哪类就做哪节,一节几行)

| 场景 | 多做的一项 | 判据 |
|---|---|---|
| **资金**(余额、结算、分账、退款) | 走一次失败路径,把失败原因排除后再走同一条路 | 第二次必须成功——失败没有在库里留下挡住下次的东西(幂等键 / 锁 / 状态) |
| **权限与可见性** | 用权限最低的身份直接打接口 | 「不可见」=响应体里没有,不是前端藏了 |
| **数据库迁移** | upgrade → downgrade → upgrade 回环 | 三步全过;downgrade 不裸删带外键的列 |
| **生产数据**(改口径、批量改写、删除) | 在基线树与候选分支各跑一次同一份脚本对比 | 只改声明要改的行,其余行逐字不变;有备份或可逆路径 |
| **重建 / 替换类**(依赖、环境、目录) | 扫旧物残留 | 旧路径、旧包、旧配置零命中 |
