## 一、两条线是谁

| | 匿名客户(看客态) | 订单客户(用户态) |
|---|---|---|
| 从哪来 | 主播/顾问/商会引流(信任是**转移**来的,他先喜欢的是人不是平台) | 付过钱,账号随单诞生(**账号=成交的沉淀**,无注册动作) |
| 心理主线 | 警惕:"这是啥地方?会不会骗我?"耐心以秒计 | 期待+焦虑:"到哪了?轮到谁动?" |
| 平台任务 | 不辜负转移来的信任:**认真、不烦人、说话算数** | 两个字:**不利用**;订单五个舒服 |
| 身份 | 匿名ID(浏览器侧,归因随身带,㉜首触) | 手机号=身份锚(验证码轻账号,无密码) |

**动作三层法**(两态之间的门槛设计):看=零门槛 → 记(收藏/我也要)=验证码即建账 → 付=托管。

## 二、逐页设计方法(创始人方法,固定套路)

对任何消费者可见的页面/功能,按此表推导,综合列即决策:

```
| 维度 | 匿名客户 | 订单客户 |
| 进来时心境(真实独白) | ? | ? |
| 要达到的感受(一句话) | ? | ? |
| 策划要点 | 骨架给证据 | 适应给捷径 |
| 综合需要 | (一句话,即本页决策依据) |
```

要求:心境必须写成**消费者独白**(第一人称大白话),不许写抽象词("提升信任感"不合格,"我是不是被骗了?"合格)。

## 三、总决策原则(先背再设计)

1. **生人要证据,熟人要捷径;信息一层,便利两层**——页面骨架给证据(确定性内容不可省),登录态只加便利(预填/直达/历史)。一套页面两种状态,不做两版。匿名与登录的区别永远是便利差异,不是信息差异(公开层只有一层,不做登录解锁内容)。
2. **成交动线与发现动线物理分离**(㊶)——成交页(服务卡页→付款→凭证)零打岔、不推荐任何其他服务;发现归类目页/完成页。别让选择杀死冲动。
3. **付款后第一屏是平台的第一次履约**——付款后 0-60 秒是信任最低谷,凭证页=填低谷+轻账号出生证(手机号即账号、短信随时回来)+跟单入口。
4. **克制本身是体验**——不弹窗、不索要、不推销、不召回推送(㊴)、无忠诚度计划(㊵:无积分/会员/券,忠诚=每单办成+从不利用)。
5. **焦虑的反义词不是快,是可见**——订单页任何时刻打开,三秒看懂:到哪了/下一步/轮到谁动/要不要我动。
6. **文案即界面,界面即正规**(㊳消费者词汇表)——状态机名词零直出,全量消费者可见文案走受控映射表,说人话("澄清中"→"顾问正在帮你把需求整理清楚")。
7. **异常三问,一屏答完**——任何异常触点(满员/下架/付款中断/拒单/退款)同屏回答:怎么了(人话)/钱呢(资金状态)/然后呢(下一步+门)。**链接不死**(对外链接永远落到有意义的页面);错过给出口,出事给时限;不做假紧迫。详见《异常路径体验策划》。

## 五、页面速查(详版见《页面体验规格》)

| 页面 | 综合需要一句话 |
|---|---|
| 服务卡页 | 三秒对上号、十秒看懂、三十秒敢付钱;确定性三件(托管/不含什么/出问题平台管)在付款按钮前 |
| 名片页 | 一页立住一个人——生人验真,熟人续缘(指名复购置前) |
| 付款凭证页 | 把信任最低谷填平;轻账号出生证 |
| 首页 | 生人看懂平台,熟人一步到事(登录态订单置顶,路由不是海报) |
| 类目页 | 根据地门面,密度可感,"能办的事比我以为的多" |
| 需求摘要页 | 别人的需求是我的灵感(脱敏摘要+我也要克隆预填) |
| 协作页(消费者视角) | 每次打开必有确定答案;全量走词汇表 |
| 我的 | 安静的抽屉:资产感落点,零营销位 |

打磨预算排序:服务卡页 > 凭证页 > 协作页 > 名片页 > 首页。

**页面基座五件**(所有对外页面标配,新页面默认自带):页脚咨询入口/隐私一句话告知/page_view 埋点+referrer 随身带/㊳词汇表文案/异常终态有出口(链接不死)。
**成交故事落点**(㊿):名片页+类目页+需求池流;不进首页、不进服务卡页。**被传的页面自带归因**:名片页/服务卡页分享即携带归因码。
**工程前提**:匿名可见页面依赖公开层(《公开层设计》)——评审时先确认接口不挂登录墙。

## 六、使用场景

1. **设计新页面/功能**:按第二节表格推导,产出并入权威库对应策划文档;
2. **评审设计稿/前端实现**:按第三节原则+第四节红线逐条过,browser-harness 走查时以第五节"综合需要"为验收语;
3. **写消费者端开发 prompt**:引用本 skill 相关条目+权威库路径,验收标准必含对应页面的"综合需要";
4. **写消费者可见文案**:先查㊳词汇表(建成前:按"说人话"标准写并提请入表)。
